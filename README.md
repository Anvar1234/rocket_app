**README**

**Описание задачи:** получить json из тела запроса и переложить на объекты соответствующей структуры.

**Механика:**
В контроллере получаем json из тела POST (так легла душа) запроса, десериализуем джексоном в список ДТО-объектов, отправляем список в сервис, где разбираем его в foreach на отдельные элементы и маппим ДТО-шки с помощью MapStruct (основной +вспомогальный маппер) в объекты доменного класса, собираем стрингбилдером, с помощью toString() возвращаем строку из стрингбилдера.

**Особенности:**
1. ДТО и доменный класс маппится один к одному, без извращений.
2. Маппер определен один общий, и один вспомогательный, без него коляска не ехала нормально.
3. Сервис автовайрится в контроллер в виде интерфейса, благодаря чему реализована возможность выбора поведения приложения через окружение (prod или !prod == любой (test, dev, omlet и тд) другой). В любом другом возвращается просто тестовая строка.
4. Заработало со второго раза, что не может не радовать)
